# CV web de Adrian Sotolongo Rodríguez

Sitio estático para GitHub Pages. Archivos: `index.html` (contiene el diseño, los textos en inglés y español, y los botones). No hace falta instalar nada.

## Publicar
1. Crear cuenta en github.com (si aún no existe).
2. Crear un repositorio **público** llamado `NOMBREUSUARIO.github.io` (sustituir por el nombre de usuario de GitHub).
3. Abrir el repositorio, seleccionar **Add file > Upload files** y subir el archivo `index.html` (no el ZIP); confirmar con **Commit changes**.
4. Abrir **Settings > Pages > Build and deployment** y seleccionar **Deploy from a branch**, rama `main`, carpeta `/(root)`, **Save**.
5. Visitar `https://NOMBREUSUARIO.github.io` cuando termine la publicación.

## Actualizar
Editar `index.html` en GitHub (icono de lápiz) y modificar el objeto JavaScript `data` en la parte inferior. Cada experiencia nueva debe tener textos `en` y `es`. Confirmar con **Commit changes** y volver a comprobar las dos versiones y el PDF.

## Guardar en PDF
En la página pulsar **PDF / Print**, seleccionar **Guardar como PDF**, tamaño **A4**, escala **100 %** (ajustar si fuera necesario), desactivar cabeceras/pies del navegador y activar gráficos de fondo. Verificar especialmente la paginación. El diseño A4 es aproximado y requiere ajustes si los textos crecen.

## Antes de publicar
- Revisar si se desea exponer públicamente correo y teléfono.
- Sustituir el enlace provisional de LinkedIn por la URL real.
- Añadir una URL real de portafolio.
- Verificar fechas, nombres y traducciones; las traducciones iniciales son una propuesta de trabajo.
- Probar en móvil y navegador de escritorio.

GitHub Pages es un alojamiento **público**. No subir documentos confidenciales.
